🚀 HOW TO GET STARTED
═══════════════════════════════════════════════════════════════════════════════

Step 1: Read Documentation (Choose your path)
   → For quick setup: QUICK_START.md (5 min)
   → For full details: README.md → HACKATHON_SUBMISSION.md (20 min)
   → For technical depth: PROJECT_SUMMARY.md (25 min)

Step 2: Local Setup
   $ git clone <repo>
   $ cd vault-medics
   $ pnpm install
   $ cp .env.example .env.local
   (Add DATABASE_URL, BETTER_AUTH_SECRET, AI_GATEWAY_API_KEY)
   $ pnpm dev

Step 3: Deploy to Blockchain (Optional)
   - Get CFLR tokens: https://faucet.flare.network/
   - Run: npx hardhat run scripts/deploy.ts --network coston2
   - Update: NEXT_PUBLIC_REGISTRY_ADDRESS in .env.local

Step 4: Test Everything
   - Follow TESTING_GUIDE.md for comprehensive testing
   - Verify on Coston2 Explorer

Step 5: Submit to Hackathon
   - Use details from HACKATHON_SUBMISSION.md
   - Record demo video
   - Submit to hackathon platform
